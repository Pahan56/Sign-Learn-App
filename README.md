# SignLearn

## 📱 Project Description

SignLearn is an interactive mobile application designed to help users learn sign language in a simple and engaging way.

The application provides learning materials for alphabets, numbers, and everyday words. It also includes interactive quizzes to help users practice their knowledge and improve their learning experience.

## ✨ Features

- Home Screen
- Learning Menu
- Alphabet Learning (A–Z)
- Number Learning (0–9)
- Everyday Sign Words
- Search Functionality
- Word Categories
- Image-Based Learning
- Interactive Quiz
- Score Calculation
- Quiz Results and Feedback
- Offline Learning Support

## 🛠️ Technologies Used

- **React Native** – Mobile Application Development
- **Expo** – Development Framework
- **JavaScript** – Programming Language
- **SQLite** – Local Database Management
- **React Navigation** – Screen Navigation
- **Git and GitHub** – Version Control and Project Collaboration

## 📚 Learning Modules

### Alphabet

Learn letters from A to Z using images and learning materials.

### Numbers

Learn numbers from 0 to 9 through visual learning materials.

### Everyday Words

Explore common sign language words using images, categories, and search functionality.

### Quiz

Test your knowledge through interactive questions, answer feedback, and score calculation.

## 📡 Offline Usage

SignLearn supports offline learning by using locally stored learning data and images.

Users can access the available learning materials and practice quizzes without requiring a continuous internet connection.

## 🎯 Project Objective

The main objective of SignLearn is to provide a simple, interactive, and user-friendly mobile learning experience that helps users understand and practice sign language through visual learning materials and quizzes.
